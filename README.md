# The DCF Workbook

An interactive website that teaches discounted cash flow (DCF) valuation to A-level students. Students work through six short chapters, then build a simplified DCF model for Bubble & Co, a fictional bubble tea chain.

## What's inside

1. **Time value of money**: why £100 today is worth more than £100 next year
2. **Free cash flow**: turning operating profit into cash
3. **The discount rate**: risk, plus an introduction to WACC and CAPM
4. **Terminal value**: the growing perpetuity formula
5. **Build a DCF**: a guided six-step model with cautious, base and optimistic scenarios
6. **Sensitivity**: how much the answer moves when the assumptions change

There's also an eight-question quiz, a glossary, a privacy policy and terms and conditions.

## Running it

The whole site is one file, `index.html`, with no build step and no dependencies. Open it in any modern browser.

To publish it with GitHub Pages: go to **Settings > Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Privacy and security

- The site collects no personal data. There are no accounts, forms, cookies, analytics or ads.
- Exercise and quiz answers are checked in the browser and never sent anywhere.
- Progress checkpoints are saved only in the visitor's own browser (local storage key `dcf-workbook-progress`). Visitors can delete them from the privacy policy page.
- A Content Security Policy blocks every outside connection except Google Fonts, and outgoing links send no referrer.
- The only third party is Google Fonts, which receives a visitor's IP address when the fonts load.

## Disclaimer

For learning only. This is not financial advice. Bubble & Co and all its figures are made up.
